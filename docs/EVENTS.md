# افزودن و به‌روزرسانی مناسبت‌ها بدون تغییر کد

از نسخه‌ی ۱.۲.۰ می‌توانید مناسبت‌های جدید (یا اصلاح‌شده) را با یک فایل JSON اضافه کنید — بدون دست‌زدن به کد افزونه.

## محل فایل (اولویت با فایل کاربر است)

1. `~/.config/shamsi-calendar/extra-events.json` — فایل شخصی شما؛ با به‌روزرسانی افزونه از بین نمی‌رود
2. `<extension>/events/extra-events.json` — فایل همراه افزونه؛ برای انتشار مناسبت‌های به‌روزشده در ریلیزها

اگر فایل اول موجود باشد، فقط همان خوانده می‌شود.

## قالب فایل

```json
{
  "persian": {
    "6/12": [["سالگرد ازدواج ما", false, 1]]
  },
  "islamic": {
    "9/21": [["شب قدر (نمونه)", false, -1]]
  },
  "gregorian": {
    "12/25": [["کریسمس", false, 1]]
  }
}
```

- کلید بیرونی: نوع تقویم — `persian` (شمسی)، `islamic` (قمری)، `gregorian` (میلادی)
- کلید داخلی: `"ماه/روز"` بر اساس همان تقویم
- هر رویداد: `["عنوان", تعطیل, شادی]`
  - **تعطیل**: `true` روز را قرمز و تعطیل می‌کند
  - **شادی**: `1` شاد، `0` عادی، `-1` عزاداری

## نکته‌ها

- بعد از تغییر فایل، یک بار GNOME Shell را ری‌استارت کنید (خروج/ورود در Wayland) تا کش پاک شود.
- مناسبت‌های متحرک (مثل «آخرین پنجشنبه‌ی ماه») پشتیبانی نمی‌شوند؛ آن‌ها در کد `src/events/` محاسبه می‌شوند.
- خطای قالب JSON باعث نادیده‌گرفتن کل فایل می‌شود؛ خطا در `journalctl` با برچسب `ShamsiCalendar` ثبت می‌شود.

## رویدادهای شخصی (فرم داخل پاپ‌آپ)

رویدادهایی که با دکمه‌ی «+ افزودن رویداد» ثبت می‌کنید در **Evolution Data Server** ذخیره می‌شوند (نه این فایل) و با GNOME Calendar و — در صورت انتخاب تقویم گوگل — با Google Calendar همگام می‌شوند.

محدودیت شناخته‌شده: اگر رویدادی را که از پاپ‌آپ ساخته‌اید داخل GNOME Calendar حذف کنید، ردیف مدیریت آن (ویرایش/حذف) تا زمانی که از خود پاپ‌آپ هم حذفش نکنید باقی می‌ماند.
