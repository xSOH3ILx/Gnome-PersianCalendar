# نقشه‌ی راه (Roadmap)

## v1.1.0 — رویدادهای شخصی ✅ (انجام شد)

هدف: افزودن رویداد شخصی از داخل پاپ‌آپ تقویم که با تقویم گنوم و Google Calendar همگام شود.

- فرم افزودن رویداد (عنوان، تاریخ شمسی، ساعت شروع/پایان، یادآور) در تب جدید یا کنار لیست رویدادها
- ذخیره در Evolution Data Server (EDS) — همان مخزنی که GNOME Calendar و GNOME Online Accounts استفاده می‌کنند؛ در نتیجه سینک گوگل خودکار انجام می‌شود

### مسیر فنی

1. اتصال به EDS از طریق `Gio.DBusProxy` (سرویس `org.gnome.evolution.dataserver.Calendar8`)
2. تبدیل تاریخ شمسی انتخابی به میلادی/iCal (`DTSTART`/`DTEND`) با `Tarikh.js`
3. ساخت VEVENT و فراخوانی `CreateObjects` روی تقویم پیش‌فرض یا تقویم انتخابی کاربر
4. Fallback: اگر EDS در دسترس نبود، باز کردن GNOME Calendar روی تاریخ انتخابی (`gnome-calendar --date`)

### ریسک‌ها

- تفاوت نسخه‌ی API های EDS بین توزیع‌ها
- مدیریت خطا وقتی حساب گوگل متصل نیست (فقط تقویم محلی)
- نیاز به تست روی GNOME 46 تا 50
